# CalcHub AI – All-in-One Smart Calculator Suite

> **B.Tech Information Technology Final Year Major Project**

CalcHub AI is a state-of-the-art, production-ready web platform hosting **40+ specialized calculators** across 7 major modules (Basic, Finance, Student, Health, Unit Conversion, Daily Life, Utility). Built with **React 18, TypeScript, Tailwind CSS, Node.js, Express, MongoDB, and Gemini AI**.

---

## 🌟 Key Features

- **40+ Specialized Calculators:** EMI, Loan, SIP, FD, RD, GST, Income Tax, Salary, Scientific, GPA/CGPA, Attendance, BMI, BMR, Calorie, Unit Converters, Age, Password Generator, QR Builder, and more.
- **AI Step-by-Step Assistant:** Powered by Google Gemini AI & local mathematical breakdown engine to explain every formula, solve complex equations, and give financial/health tips.
- **Dynamic Light & Dark Mode:** Sleek glassmorphism UI with vibrant colors, micro-animations, and responsive layouts.
- **PDF & Excel Export:** Generate styled PDF reports and export calculation spreadsheets with one click.
- **Audio Readouts:** Web Speech Synthesis for audio solution readouts.
- **Authentication & Cloud Storage:** JWT Authentication, User Profile Management, Saved Favorites & Calculation History.
- **Admin Control Panel:** Metrics analytics dashboard, user directory, system status, reports, and feedback management.
- **PWA & Offline Support:** Progressive Web App manifest & service worker configuration.

## 🚀 Quick Start Instructions

### 1. Install & Run Backend Server
```bash
cd backend
npm install
npm run dev
```
*Backend runs on `http://localhost:5000`*

### 2. Install & Run Frontend Client
```bash
cd frontend
npm install
npm run dev
```
*Frontend runs on `http://localhost:3000`*
