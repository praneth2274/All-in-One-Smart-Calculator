# CalcHub AI – All-in-One Smart Calculator Suite

CalcHub AI is an enterprise-grade, full-stack web application containing **40+ specialized calculators** across 7 major modules (Basic, Finance, Student, Health, Unit Conversion, Daily Life, Utility) coupled with Google Gemini AI step-by-step mathematical explanations, JWT security, PDF/Excel reports, and dark/light glassmorphism UI. Designed for B.Tech Information Technology Major Project evaluation.

## Tech Stack Overview

### Frontend
- **Framework:** React 18 (Vite, TypeScript)
- **Styling:** Tailwind CSS, Custom Glassmorphism UI, Framer Motion
- **Icons & Visualization:** Lucide React Icons, Recharts
- **Document Export:** jsPDF, SheetJS (XLSX)
- **Speech Capabilities:** Web Speech Recognition & SpeechSynthesis APIs

### Backend
- **Runtime:** Node.js, Express.js REST API
- **Security:** JWT Authentication, bcryptjs, Helmet, Express Rate Limiting, CORS
- **Database:** MongoDB Atlas + Mongoose ORM (with in-memory fallback)
- **AI Integration:** Google Gemini AI API + Step-by-Step Solver Engine
